Noxus Copilot

Connect a Noxus agent to act as your copilot on any website. It detects page context natively on Salesforce and HubSpot, and sends general page context everywhere else.

Paste your agent's public chat-widget / deployment embed URL.
You can also drag the left edge of the panel to resize.

Authentication (Noxus user)

Required only when the deployment uses Noxus user auth. Configure an Auth0 application (SPA / native, Authorization Code + PKCE) with the redirect URI below, then fill these in. Leave blank for public/anonymous embeds.
